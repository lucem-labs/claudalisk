These tools answer questions about C# and TypeScript code by symbol name, so use them instead of reading whole files to trace, rename or edit a symbol: ${mcpTools}. A name is Namespace.Type.Member for C# (any trailing part) or folder/or/file:exportedName for TypeScript. An ambiguous name is refused with its candidates.

- find, definition, implementations, callers, callees, references and diagnostics take name
- rename takes name and newName
- replaceBody takes name and body
